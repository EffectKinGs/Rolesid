# ملفات موقع IAA Portal

هذه حزمة واجهة دخول IAA Portal التفاعلية. تحتوي على نموذج بريد إلكتروني وكلمة مرور، إظهار وإخفاء كلمة المرور، Remember Me، تبديل العربية والإنجليزية، ورسائل الحالة المحلية.

## التشغيل

1. ثبّت Node.js و pnpm.
2. شغّل `pnpm install`.
3. شغّل `pnpm dev:static`.
4. افتح العنوان الذي يظهر على المنفذ 3000.

لبناء نسخة الإنتاج استخدم `pnpm build:static`، وستجد الملفات الناتجة داخل `dist/public`.

> تسجيل الدخول في هذه النسخة تجريبي ومحلي؛ لا يتم إرسال البريد أو كلمة المرور إلى خادم.
