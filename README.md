# IAA Portal — International Affairs Agency

بوابة رول بلاي لقطاع **NoNe**، تعمل كموقع ثابت (بدون build) ومهيأة للنشر على Netlify.

## الملفات

```
index.html                 نقطة الدخول
netlify.toml               إعداد النشر
assets/
  css/style.css            كل التصميم
  js/config.js             الإعدادات (الأدمن، الرتب، Firebase، الخريطة، الشعار)
  js/db.js                 طبقة قاعدة البيانات (Firebase أو وضع تجريبي محلي)
  js/app.jsx               منطق الموقع والصفحات
  img/iaa_seal.svg         ختم IAA الاحتياطي
  img/logo.png             (ضعه أنت) شعار القطاع الحقيقي، يظهر تلقائياً
  img/map.jpg              (ضعه أنت) صورة الخريطة التكتيكية
```

## قبل النشر

1. **الشعار:** ضع صورة شعار القطاع باسم `assets/img/logo.png`.
2. **الخريطة:** ضع الصورة باسم `assets/img/map.jpg` (روابط ديسكورد تنتهي صلاحيتها).
3. **الأدمن:** غيّر `ADMIN.password` في `assets/js/config.js` (الافتراضي `123456`).
4. **Firebase:** استبدل قيم `FIREBASE` في `config.js` بإعدادات مشروعك.
   - إذا تركتها `YOUR_...` يشتغل الموقع بوضع تجريبي محلي (البيانات تُحفظ في متصفحك فقط).
   - أسماء المجموعات (`police_*`) هي نفسها في النسخة القديمة، فبياناتك الحالية تظهر مباشرة.

## تسجيل الدخول

- الأدمن: `none@iaa.gov` + الباسورد من `config.js`.
- الموظفون: يضيفهم الأدمن من تبويب **Staff → Enroll New Agent**. الإيميل لازم ينتهي بـ `@iaa.gov`.
- كلمات مرور الموظفين الجديدة تُحفظ مشفّرة (SHA-256)، والحسابات القديمة المحفوظة كنص عادي تظل تعمل.

## التشغيل محلياً

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080` (لا تفتح index.html مباشرة بالنقر، لأن ملفات JS تحتاج خادماً).

## النشر على Netlify

اربط المجلد بمستودع GitHub ثم **Add new site → Import an existing project**:
Build command: فارغ — Publish directory: `.`

## ملاحظة أمنية

تسجيل الدخول يتم من جهة المتصفح، وقواعد Firestore لازم تكون مفتوحة للقراءة والكتابة ليشتغل الموقع.
هذا مناسب للرول بلاي، لكن لا تستخدم فيه كلمات مرور حقيقية.
